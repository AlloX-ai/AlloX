# AlloX

AlloX is an AI-powered platform. Learn more at **https://allox.ai**.

## Tech Stack

- TypeScript
- Vite
- Tailwind CSS
- ESLint

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- Yarn

### Installation

```bash
git clone https://github.com/AlloX-ai/AlloX.git
cd AlloX
yarn install
```

### Run locally

```bash
yarn dev
```

The app will be available at `http://localhost:5173`.

### Build for production

```bash
yarn build
```
